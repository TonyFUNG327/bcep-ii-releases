# ZeroEntry BCEP II – Releases

This repository hosts official update packages for ZeroEntry BCEP II.

BCEP II checks here for updates and installs them for you. You do not need to download anything manually: open BCEP II and use **Updates > Check now** if you want to check straight away.

Each release contains the installer and a signed update file that records the installer's size and checksum. BCEP II checks the signature and the installer against it before installing.
